# Power BI

## Report

`Return analysis.pbix` contains the Power BI report used for the analysis.

### Report structure

**Page 1 — Executive Decision View**
- Return Rate
- Returned Orders / Units
- Monthly return trend
- Return reasons
- Category return performance
- Channel context

**Page 2 — Diagnostic / Action View**
- Average Return Days
- Product return performance
- Top return category/reason
- Subcategory × Return Reason
- Discount vs Return Risk
- Product detail

The dashboard is designed around the business decision rather than around displaying every available field.
