# Portfolio Story — Decision-Driven Return Analysis

## 1. Business Context

An e-commerce business is facing a meaningful product-return burden. The goal of this analysis is not to build a dashboard for its own sake, but to identify **which return problems deserve action first**.

## 2. Decision

**Which return problems should the business fix first to reduce customer returns and refund exposure?**

The analysis is designed to help a merchandising/operations stakeholder decide where to focus improvement effort rather than trying to optimize every return reason at once.

## 3. North Star Metrics

| Metric | Definition | Decision use |
|---|---|---|
| Return Rate % | Returned Orders ÷ Total Orders | Overall return-risk signal |
| Returned Units | Sum of returned quantity | Measures problem scale |
| Refund Amount | Derived refund exposure from returned quantity, paid price and refund deduction | Measures financial impact |
| Average Return Days | Return Date − Delivery Date | Indicates return timing |

## 4. Analysis Path

The analysis follows a simple decision path:

**Size → Why → Where → Prioritize → Recommend**

### Size

Establish the size of the problem: 3,100 orders, 745 returned orders and a 24.03% return rate.

### Why

Standardize return reasons and identify the largest return drivers.

### Where

Break return performance down by category, subcategory, product and channel to identify concentration.

### Prioritize

Do not rank problems only by volume. Use three lenses together:

**Return volume + return rate + financial exposure**

### Recommend

Turn the prioritized problems into actions with a responsible team and a measurable KPI.

## 5. Evidence-Based Insights

### Insight 1 — Returns are concentrated

**Finding:** Product Not As Expected (228 units), Wrong Size (217) and Damaged Product (184) total 629 returned units, or 56.5% of returned units.

**Why it matters:** The business can focus improvement effort on a small set of high-impact problems rather than treating all return reasons equally.

**Action:** Start with these three problems.

### Insight 2 — Operational volume and financial exposure tell different stories

**Finding:** Fashion has the highest returned-unit volume, while Electronics has the highest derived refund exposure.

**Why it matters:** A volume-only priority list can miss financially expensive issues.

**Action:** Review both returned units and refund exposure before deciding where to invest effort.

### Insight 3 — Damage is an operational investigation area

**Finding:** Damaged Product contributes approximately ₹8.03L in derived refunds.

**Why it matters:** Damage has enough financial exposure to justify operational investigation.

**Action:** Audit packaging and handling for products with elevated damage returns.

## 6. Recommendation Framework

| Priority | Action | Stakeholder / Owner | Success KPI |
|---|---|---|---|
| 1 | Improve product-page images, descriptions and specifications | Merchandising / Content | Product Not As Expected rate |
| 2 | Improve size charts and fit guidance | Fashion / Merchandising | Wrong Size rate |
| 3 | Audit packaging and delivery/marketplace handling | Operations / Logistics | Damage rate + Refund Amount |

These recommendations are **hypotheses to test**, not proven causal conclusions.

## 7. Expected Business Impact

The project does not claim a realized savings figure because no intervention was executed. Instead, the analysis identifies a measurable opportunity:

- 56.5% of returned units are concentrated in the top three reasons.
- Approximately 52.0% of derived refund exposure is tied to those three priority reasons.
- Success should be measured by reduction in overall return rate, reason-specific return rates, returned units and refund exposure after interventions.

## 8. What Would Be Validated Next

The dataset alone cannot prove why a customer experienced a return. Root-cause hypotheses should be validated using customer feedback, product-page history, packaging/carrier information, seller/vendor information and controlled tests.

## 9. Interview Story

> “I started with a business decision rather than a dashboard. I wanted to identify which return problems an e-commerce business should fix first. I defined return rate, returned units, refund exposure and average return days as my North Star metrics. I then analyzed why returns happen, where they are concentrated, and prioritized problems using return volume, return rate and financial impact. The top three reasons accounted for 56.5% of returned units, so I recommended focused actions for product-page quality, size guidance and packaging/handling, each tied to an owner and KPI. I treated the root causes as hypotheses because the dataset can show patterns, not prove causality.”
