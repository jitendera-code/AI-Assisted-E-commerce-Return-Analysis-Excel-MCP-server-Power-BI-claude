# Resume-Ready Project Bullets

## Recommended version

**E-commerce Return & Refund Analysis | Power BI, DAX, Excel**

- Analyzed **4,286 order-line records across 3,100 orders** to identify return drivers, refund exposure, category/channel concentration and product-level risk.
- Built a **Power BI star-schema model and DAX KPI layer** to measure **745 returned orders, 24.03% return rate, 1,113 returned units and ₹38.17L derived refunds**.
- Applied **Pareto analysis, heatmap diagnostics, MoM indicators and return-risk analysis** to identify the top three return reasons contributing **56.5% of returned units**.
- Translated findings into prioritized actions for product content, sizing, packaging/handling, vendor quality and discount-risk monitoring, with measurable success KPIs.

## Short ATS version

- Built Power BI/DAX return analytics on **3,100 e-commerce orders**, identifying a **24.03% return rate** and **₹38.17L refund exposure**.
- Used Pareto and diagnostic analysis to identify **Product Not As Expected, Wrong Size and Damaged Product** as **56.5% of returned units**.
- Delivered business recommendations tied to return-rate and refund KPIs.
